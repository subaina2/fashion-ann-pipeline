
# Fashion-MNIST ANN Pipeline

hotfix branch testing changes

## Project Overview

This project classifies Fashion-MNIST clothing images
into 10 categories using a fully connected Artificial
Neural Network (ANN)


## Dataset

Fashion-MNIST contains 70,000 grayscale images.
60,000 images are used for training and 10,000
images are used for testing.

## Technologies

- Python
- TensorFlow
- Git and GitHub
- DVC
- Google Drive

## Objective

Build a reproducible machine learning pipeline
with a target test accuracy of at least 85%.
